1. Outline the Functional requirements (take only 3)
2. Outline non-functional requirements (this helps us in dives)
3. Draft the API design and make modifications as you go
4. Give very high-level design
5. Go through non-functional requirements and make the necessary modifications ^zPDFuRxh

Dropbox: The tool that lets you sync files across remote and local folder ^K7URd9kd

Functional Requirements
1. Users should be able to upload files
2. Users should be able to download files
3. Users should be able to sync files across remote and local ^3Lwqyf51

Non-functional Requirements
1. Users can be able to upload large files (~50GB)

3. Low latency (as low as possible)
